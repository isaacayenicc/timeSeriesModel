# Figure and table sources

| Figure directory | Original numeric source |
|---|---|
| figures/eda | results/eda, results/record_inventory.csv, results/eda_feature_hypotheses.csv |
| figures/optimization | results/optimization/trials.csv and pareto_front.csv |
| figures/comparison | results/predictions, results/metrics/all_model_comparison.csv, results/statistical_tests/paired_moving_block.csv |
| figures/fault | results/fault cohort, stress, pulse and label-free nuisance summaries |
| figures/report | report-specific derivatives regenerated by scripts/build_report.py |

The document and deck builders read these files and record verification logs. Tables retain the same standardized error units, target range and source scope. The selected PI-SRC, historical frozen SRC and externally published paper have distinct scope labels.
