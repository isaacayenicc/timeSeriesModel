# Source and input attribution

The new PI-SRC study uses the user-supplied MECG 7780 data and course materials. The project does not grant redistribution rights to the course handout, signal recordings, articles or third-party archives. Locate original inputs by the SHA-256 records in the input inventory. The distributable package omits those original inputs.

Frozen comparator source and numeric checkpoints reuse the user's earlier `timeSeriesModel` work, including the expanded comparator study and selected support-refit and archived checkpoint adapters. Their provenance and byte hashes are recorded in `results/metrics/baseline_replay_provenance.json` and the original-input manifest. Historical archive filenames identify source evidence. New model names follow the SRC taxonomy. The independent project copies the minimal code and numeric artifacts necessary for replay.
