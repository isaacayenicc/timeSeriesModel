| Requirement | Evidence and scope |
| --- | --- |
| Source and acquisition audit | Bundled prior project's input inventory and EDA. Original input and archive sources remained unchanged. |
| 21 requested model families | Expanded model checkpoints, solver/training code and run tables. Nineteen new fits with guarded selection and two QR refits of frozen sparse supports. |

| Fault diagnostics | Prespecified common subset for all runnable models, whole-corpus for four models and raw, explicit overlaps and provisional A/B groups. Verified class labels and MATLAB gold fixtures unavailable. |
| Prediction and diagnostic stress | Six fixed RPM scenarios, inference/angle paths, paired periodic/aperiodic injection for full-scope models. |
| Blind evaluation | Hash-checked missing-input preflight. Independent files and authoritative labels are unavailable. |
| Reproducibility | New and prior packages together, portable numeric checkpoints, tests and notebooks. Matched historical results retain earlier validation choices without re-tuning the primary DHON. |
| Course documents and presentations | Prior report and both timed decks remain bundled. The expanded companion and editable addendum cover these additional comparisons. |
