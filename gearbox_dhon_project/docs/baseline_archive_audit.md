# Conventional and oscillator archive audit

## Sparse LPV-ARMA reproduction

The inspected `core.py` implements simulation, normalized polynomial design, differenced ARI/ARIMA, ADMM and angular PMI. The experimental workflow in `experiment.py` uses shifted Legendre coordinates for dense AIC, monomials for LASSO, five random row folds, a one-standard-deviation penalty rule, coordinate descent and rank-aware support refitting. Relative histories overlap between those folds. The previous fit reports final dual gaps 0.12951 and 0.08569, with larger fold gaps possible. Those supports are useful frozen historical references and cannot establish solver convergence. The original common start is 316. The new strict fits use past speed, converged ADMM, guarded folds with fold-local orders and proxies, and a 1,792-sample common score mask. The printed monomial versus textual Legendre ambiguity is reflected explicitly in the basis selection.

`simulation_reproduction.py` uses an approximate speed profile, fixed noise seeds and an explicit Eq. 25 envelope convention. Several frequencies exceed Nyquist for some simulated speeds. Its source reports simulated sparse LPV-ARMA MSE 0.52423 versus published 0.3570, and F1 area 0.5257 versus published 0.9981. These results are historical and do not reproduce the original simulation quantitatively. The archival experimental checkpoint was replayed by a separately implemented predictor and reproduces the prior validation MSE to machine precision. `outputs/metadata.json`, `table5.csv` and `table6_comparison.csv` provide the archival order, support, convergence and mask provenance.

## Improved DHON and NG-RC

The inspected `optimize_improved.py` builds speed-conditioned time and angle delays, frozen demodulating oscillator states and an innovation proxy. The DHON head learns gated readout mappings and adaptive mixing of fixed time constants. Gradient descent changes head weights, while the frequency/order references and damping in the feature bank stay fixed. `fast_predict.py` batches the same inference. `slow_correction.py` adds a clipped, lagged, exponentially weighted residual state with a fixed 1,024-sample memory. `local_refine.py` tests alternative fixed oscillator memories and correction governors. `compare_ablations.py` evaluates a matched correction for linear, nonlinear and ancestor controls. `predict_record.py` is a saved inference entry point. `run_all.py` orchestrates command-line steps. Source files were inspected in a separate read-only extraction and no top-level archive code was executed.

The prior summary reports 690 scored configurations and 2,070 fold rows. Those counts and previous optimization logs are historical. The new project independently evaluates the shipped weights for optimized DHON, optimized NG-RC, the corresponding linear control, both local checkpoints, and a second DHON seed, each with and without the same frozen correction. The frozen corrected DHON and linear control score 0.316889 and 0.318194. Maximum elementwise error against a supplied checkpoint-backed forecast is 2.41e-6. The corrected ancestor score is 0.316445, independently rescored from the supplied target-aligned forecast. The ancestor model weights and executable source were absent, so the checkpoint replay status for that row is `prediction_artifact_only`.

The archived correction reduces MSE by 0.007995 in the expanded DHON and 0.007841 in the matched linear readout. At common correction, the expanded nonlinear model's absolute advantage over linear is 0.001305. The scale of these effects supports treating the correction and learned harmonic readout as separate contributors. Candidate labels are undocumented in the supplied data. A historic group-assignment AUC does not establish fault classification against confirmed labels.

The replay uses independent NumPy and SciPy code in `gearbox_dhon.archived` with `allow_pickle=False` for checkpoints. The historical validation records were matched using exact array equality and the archive train/validation MAT copies matched the directly supplied files by SHA-256. `reference/combined_predictions.npz` and saved predictions were inspected, and only the forecast arrays used for this benchmark are included. No raw archive MAT records are packaged.

The expanded checkpoint's causal oscillator history is 512 samples, its longest innovation path uses 280, and its 8 mesh-cycle angular window needs fewer than 340 at the supplied RPM. The matched correction adds 1,024 previous errors to that history, keeping the expanded control within the 1,792 common guard. The archive replay checks establish zero forecast change through index 12,000 when RPM and vibration are changed from that index onward.
